## 📌 Descripción del proyecto
Se deben incorporar distintas funcionalidades:
- Mostrar los supervillanos con su fotografía y descripción.
- Respetar SPA.
- Agregar un botón "Eliminar" para cada supervillano.
- Agregar un botón "Ver Imagen" para cada supervillano, apareciendo un modal con su imagen.
- Incorporar un formulario para escribirle al superjefe. Para ello, se debe emplear un enlace en el header "Escribir al SuperJefe".  
Los campos que debe tener el formulario son :
  - Remitente: texto con 20 caracteres máximos. Es un campo obligatorio.
  - Edad: numérico con un máximo de 2 cifras. Es un campo obligatorio.
  - Mensaje: texto con 10 caracteres mínimos y 14 caracteres máximos. Es un campo obligatorio.
- Agregar botón dinámico:
  - Color verde: "Firmar la Paz"
  - Color rojo: "Declarar la guerra".

- Utilizar directivas.

 

## Ejecutar el proyecto
Introducir la siguiente línea de comando: 

```bash
ng serve
```
